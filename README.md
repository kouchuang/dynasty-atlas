# 中国历代数字博物馆 · Dynasty Atlas

一个面向中国历代王朝的数字历史展陈计划。当前收录第一展厅：**大宋风华（960—1279）**，后续将逐步补充唐、汉、明、清等朝代。

- GitHub Pages 入口：<https://kouchuang.github.io/dynasty-atlas/>
- 完整源码：`index.html`
- 本地使用：直接用浏览器打开 `index.html`，无需联网、服务器或第三方依赖。
- 旧入口：`song-dynasty.html` 会自动跳转到展馆首页，保留旧链接兼容。

## 当前展览：大宋风华

以帝王世系、人物关系、官制演变和历史长河四条线索，展示两宋三百余年的历史。

- 18 位宋朝皇帝，独立档案包含继位、政绩、事件、人物、评价、争议与参考史料。
- 61 位人物、107 组有明确史料说明的关系网络。
- 五个官制阶段、35 个机构 / 官职条目，解释官、职、差遣及二府三司、元丰改制等制度问题。
- 49 条历史纪事，支持时期、类型与疏密筛选。
- 人物关系图支持筛选、拖拽、缩放、点击节点 / 连线；全站支持搜索和本地浏览状态保存。

## 史源与说明

关键年代、人物关系与制度沿革依据《宋史》《续资治通鉴长编》《宋会要辑稿》《文献通考》《建炎以来系年要录》《三朝北盟会编》《金史》《元史》等史料，并参以龚延明、邓小南、邓广铭、漆侠、王曾瑜、寺地遵、包伟民、虞云国等学者的研究。页面内对异说与争议有明确标注。

本仓库是个人学习性质的非官方历史数字展，不替代原始史料与专业研究，也不代表任何机构。
